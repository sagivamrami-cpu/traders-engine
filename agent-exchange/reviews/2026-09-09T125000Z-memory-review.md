Important:

1. Ambient Decimal precision changes the causal admission boundary.
   `trading_system/tree_replay/state.py:67` constructs `observed_epoch` using Decimal division and addition under the caller's active context; the comparison at `trading_system/tree_replay/state.py:81` therefore need not use the exact observation time. With `localcontext().prec = 10`, observation `2026-09-07T10:00:00.900000+00:00` becomes an epoch boundary of `1788775201`, and payload `{"ts":1788775200.95}` is accepted despite being 50 ms in the future. Default precision 28 correctly rejects the same event. This violates point-in-time correctness and makes identical supplied evidence depend on ambient numerical state. Construct the epoch Decimal exactly without context-sensitive arithmetic, or isolate arithmetic in an explicitly sufficient context. Add a regression that requires the same exact-boundary/future rejection behavior across caller precisions.

2. Float normalization can create a future payload and make a valid journal unrestorable.
   `trading_system/tree_replay/state.py:60` decodes floats before canonicalizing at `trading_system/tree_replay/state.py:65`, while causal validation compares the original decimal tokens at `trading_system/tree_replay/state.py:74`. These representations can disagree. At observation `2255-01-01T00:00:00.000001+00:00`, accepted payload `{"ts":8993721600.000001}` is stored and reported as `{"ts":8993721600.000002}`. `restore_memory(checkpoint_memory(journal))` then raises `ValueError: payload ts cannot exceed observed_at` at the constructor call in `trading_system/tree_replay/state.py:251`. The contract has no date restriction, so every accepted journal must satisfy the checkpoint invariant, including when epoch float spacing exceeds one microsecond. Preserve causal numeric meaning through serialization, or explicitly reject an unrepresentable payload before constructing an event; validate the stored representation as well as the original token. Add a regression covering both snapshot causality and checkpoint round-trip for this boundary. The existing decimal regression only covers a contemporary epoch (`tests/tree_replay/test_state.py:228`).
