# Historical development evidence

`sdd/` preserves task briefs, specifications, implementation reports, reviews,
patches and scratch scripts referenced by the accepted component history.
Previously these files were local-only; they are included in the 2026-09-16 handoff
so another machine can inspect the evidence behind `agent-exchange` records.

This is an archive, not the active queue. Read `/PROJECT_STATE.md` first. Dates,
local paths, process handles and partial test runs describe their original task;
later acceptance/status records supersede them. Do not execute scratch scripts
as setup instructions. Current code is under `trading_system/`, current tests
under `tests/`, and reproducible setup is in `docs/architecture/YUVAL-HANDOFF.md`.
